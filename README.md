 Tech For Girls Registration

About the Project

Tech For Girls Registration is a simple web-based registration form designed to collect participant details for the Tech For Girls community.

Features

- Registration form for participants
- Name, phone number, email ID, and college details
- Screenshot upload
- WhatsApp sharing button
- Automatic data storage in Google Sheets
- Uploaded files stored in Google Drive

Technologies Used

- HTML
- CSS
- JavaScript
- Google Apps Script
- Google Sheets
- Google Drive

How It Works

1. Open the registration form.
2. Enter the required details.
3. Upload a screenshot.
4. Use the WhatsApp sharing button.
5. Submit the registration form.
6. Registration details are saved in Google Sheets, and the uploaded file is stored in Google Drive.

Project Purpose

The purpose of this project is to simplify online registration and automate data collection.

Developer

Created as a Tech For Girls registration project.
